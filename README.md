# InvestGuard

> A modern fintech dashboard for understanding portfolio performance and behavioral investing patterns.

InvestGuard helps investors review portfolio value, gain/loss, concentration, transaction activity, and behavioral signals in one focused workspace. It is designed for reflection and education — not financial advice.

## Features

- Dark, responsive fintech dashboard UI
- Portfolio holdings, allocation, sector exposure, and performance charts
- Day, month, and year performance views
- Behavioral signals for FOMO-like buying, panic selling, overtrading, concentration, loss aversion, and timing patterns
- Interactive demo scenarios with working analysis controls
- AI-style portfolio profit and loss explanations
- English, Hindi, and Hinglish explanation modes
- Transaction journal and evidence-backed alerts
- Local-first demo data with no real brokerage connection

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:5174/dashboard](http://localhost:5174/dashboard).

## Quality checks

```bash
pnpm run lint
pnpm run build
pnpm run test
```

## Disclaimer

InvestGuard uses fictional demo data and deterministic explanations. It does not predict returns or recommend buying, selling, or holding any security.
